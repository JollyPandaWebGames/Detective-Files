# Detective Files
## Project Specification

Version: 1.0

---

# Project Vision

Detective Files is a browser-based detective simulation game.

Instead of navigating traditional game menus, players interact with a realistic police workstation where every investigation is performed through specialized applications.

The player should feel like a detective working inside a Criminal Investigation Department.

The workstation itself is the game.

---

# Design Goals

Create an immersive detective experience.

Avoid traditional menus.

Encourage observation.

Reward logical thinking.

Make players feel like investigators instead of puzzle solvers.

Support long-term expansion through new cases and new workstation applications.

---

# Core Experience

The player starts their workday by opening the police workstation.

Everything happens inside this operating system.

Future gameplay will include:

• Reading police emails

• Investigating evidence

• Watching CCTV footage

• Interviewing witnesses

• Requesting forensic analysis

• Connecting clues

• Building theories

• Writing investigation reports
