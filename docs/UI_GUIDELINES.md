# Detective Files
# UI Guidelines

Version 1.0

---

# Philosophy

The user interface should feel like a real police workstation running on a retro operating system.

It should not feel like a modern web application.

Every interface element should reinforce the illusion that the player is operating a government computer.

The UI should prioritize readability, consistency and usability over decoration.

---

# Visual Identity

Style

- Pixel Art
- Retro Desktop OS
- Police Workstation
- Dark Theme
- Professional
- Minimal
- Functional

Avoid

- Glassmorphism
- Neumorphism
- Rounded mobile UI
- Large gradients
- Excessive shadows
- Cartoon style

# Typography

Use pixel fonts whenever possible.

Recommended

- Press Start 2P (titles only)
- Pixel Operator
- Silkscreen

Body text should remain readable.

Avoid decorative fonts.

---

# Spacing

Base spacing unit

4px

Common spacing

4px

8px

12px

16px

24px

32px

Always use multiples of four.

---

# Borders

All borders should be pixel friendly.

Recommended

2px solid

Avoid

Border radius larger than 4px.

Rounded interfaces should be minimal.

---

# Icons

All icons should be Pixel Art.

Use one visual style only.

Never mix pixel icons with modern SVG icons.

Recommended size

32x32

48x48

64x64
